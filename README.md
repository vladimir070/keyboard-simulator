# Клавиатурный тренажер

## Описание

Это простой клавиатурный тренажер, написанный на Python. 
Он помогает улучшить скорость и точность набора текста, 
предлагая пользователю вводить случайные буквы из выбранного алфавита за ограниченное время. 
Поддерживаются русский и английский алфавиты.

## Возможности

*   **Выбор уровня сложности:** Пользователь может выбрать количество попыток (50, 100 или 150).
*   **Выбор алфавита:** Поддерживаются русский и английский алфавиты.
*   **Ограничение по времени:** На ввод каждой буквы дается 4 секунды.
*   **Простой интерфейс:** Игра проходит в консоли и имеет минималистичный, но понятный интерфейс.
*   **Подсчет очков:** В процессе игры ведется подсчет правильных и неправильных ответов.
*   **Выход из игры:** В любой момент игры можно выйти, введя команду `exit`.

## Как использовать

1.  **Установите Python:** Убедитесь, что на вашем компьютере установлен Python 3.
2.  **Загрузите код:** Скачайте файлы проекта из этого репозитория.
3.  **Запустите игру:** Откройте командную строку или терминал, перейдите в папку с файлами проекта и выполните команду:

    ```bash
    python <имя_файла>.py
    ```

    (Например: `python main.py`)
4.  **Следуйте инструкциям:** Игра предложит вам выбрать уровень сложности, затем алфавит и начать ввод букв.

## Управление

*   **Ввод букв:** Вводите буквы, которые отображаются на экране, и нажимайте Enter.
*   **Выход из игры:** Введите `exit` и нажмите Enter в любой момент игры.
*   **Выбор уровня сложности:** Введите номер желаемого уровня сложности (1, 2 или 3) и нажмите Enter.
*   **Выбор алфавита:** Выберите 'r' для русского алфавита или 'e' для английского.

## Зависимости

*   Python 3 (стандартная библиотека: `random`, `time`, `os`, `sys`, `select`)
